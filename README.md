# Смаженка Могилёв (Smazhenka Mogilev)

Лендинг для культовой могилёвской закусочной «Смаженка» на ул. Первомайской, 31.

Проект разработан строго на чистом HTML, CSS и Vanilla JavaScript без сторонних фреймворков и внешних зависимостей.

## Особенности проекта

- **Чистый стек:** семантический HTML5, CSS3 с дизайн-токенами в OKLCH, чистый JavaScript (ES6+).
- **Интерактивная корзина и калькулятор:**
  - Добавление и удаление блюд из меню.
  - Двусторонняя синхронизация счетчиков в карточках меню и корзине.
  - Контроль минимального заказа от **20.00 BYN** с анимированной шкалой прогресса.
  - Автоматический пересчет итогов в белорусских рублях (BYN).
  - Форма быстрого заказа к определенному времени.
- **Динамический таймер выпекания:**
  - Живой статус работы печи (08:00 – 21:00) по минскому/могилёвскому времени.
  - Обратный отсчет выхода свежей горячей партии каждые 15 минут.
- **Фильтрация меню:** классические, сытные мясные, грибные/сырные смаженки и горячие напитки.
- **Тактильные микроинтеракции (Emil Kowalski principles):**
  - Плавный физичный отклик кнопок при нажатии (`transform: scale(0.97)`).
  - Пользовательские кривые Безье (`cubic-bezier(0.23, 1, 0.32, 1)`).
  - Без ленивых `transition: all`.
  - Мобильная адаптивность с плавающей панелью быстрого заказа.
- **Локальное SEO и доступность:**
  - Полная разметка Schema.org `FastFoodRestaurant`.
  - Атрибуты доступности `aria-*`, правильная иерархия заголовков, контрастность текстов.
- **Дизайн Hallmark:**
  - 100% соответствие стандартам Hallmark (0 FAIL, 0 REFLEX, 0 WARN по sloplint).
  - Палитра румяной запеченной корочки и теплого мякиша.

## Структура файлов

```text
smazhenka-mogilev/
├── index.html       # Семантическая разметка и микроразметка
├── style.css        # Стили компонентов, сетки, анимации и адаптивность
├── tokens.css       # Дизайн-токены (цвета, шрифты, отступы, кривые Безье)
├── base.css         # Базовые правила верстки и сброс
├── script.js        # Корзина, калькулятор, таймер и интерактив
└── README.md        # Описание проекта
```

## Локальный запуск

Проект не требует сборки. Достаточно открыть файл `index.html` в любом современном браузере или запустить локальный HTTP-сервер:

```bash
# С помощью Python:
python -m http.server 8000

# Или с помощью Node.js (npx):
npx serve .
```
