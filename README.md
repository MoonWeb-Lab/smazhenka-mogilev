# Смаженка Могилёв (Smazhenka Mogilev)

Веб-приложение для сети пекарен «Смаженка» в Могилёве:
- Точка 1: ул. Челюскинцев, 37 (Пн-Пт 09:00-21:00, Сб-Вс 10:00-20:00)
- Точка 2: ул. Строителей, 31 (Ежедневно 09:00-20:00)
- Телефон для предзаказа: +375 (29) 700-70-79
- Instagram: [@smazhenka_mogilev](https://www.instagram.com/smazhenka_mogilev/)

## Стек

- React 19 + TypeScript (`strict: true`)
- Vite 6 + Tailwind CSS 3
- Framer Motion 12 (GPU-анимации и `AnimatePresence` с поддержкой `reducedMotion="user"`)
- Lucide React для UI-иконок

## Основной функционал

- Одноколоночный акцентный Hero с живым статусом работы по времени Могилёва (`UTC+3`) и карточкой адресов.
- Двухколоночный каталог меню с сегментированными вкладками категорий и клавиатурной навигацией.
- Плоское детальное окно блюда (`DishModal`) с полным составом, таблицей КБЖУ на 100 г и на порцию, выбором количества и добавлением в корзину.
- Выдвижная корзина (`CartDrawer`) с сохранением состояния в `localStorage`, прогресс-баром от 20.00 BYN, переключением самовывоза и доставки (4.00 BYN, бесплатно от 40.00 BYN), валидацией белорусского номера и политикой обработки данных.
- Локальное SEO: метатеги, Open Graph, Twitter Card, Schema.org `FastFoodRestaurant`, `robots.txt` и `sitemap.xml`.

## Команды

```bash
npm install
npm run dev
npm run build
npm run preview
```
